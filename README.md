# Site Julia Rosas | Nutricionista

Site estático (HTML, CSS e JS puros, sem build). Abra `index.html` ou publique no GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório e envie todos os arquivos desta pasta para a raiz.
2. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Onde editar
- Textos, números (`data-n`), depoimentos, CRN e links de WhatsApp (`https://wa.me/`): `index.html`
- Cores e tipografia: variáveis no topo de `style.css`
- Fotos: pasta `assets/` (troque mantendo o nome ou altere o `src` no HTML)
- Espaços de foto ainda vazios: galeria (2) — procure por `class="ph` no `index.html` e coloque um `<img>` dentro, como nos outros
